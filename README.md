## ✨ Project Overview

The project brings multiple web development exercises together on a single webpage. It demonstrates basic page structure, styling, forms, images, navigation, interactive controls, and JavaScript-based functionality.

The main page is available in [`index.html`](./index.html).

## 🧪 Features and Experiments

- HTML headings, ordered lists, and unordered lists
- Tables for daily news and class timetables
- Image maps with clickable areas
- A tea recipe using nested lists
- Restaurant order form with:
  - Text input
  - Checkboxes
  - Select menu
  - Radio buttons
  - Submit and reset buttons
- Image gallery using CSS Grid
- Navigation links for page sections
- Clickable world-map hotspots for:
  - India
  - Australia
  - United States
- JavaScript color-change button
- Increment and decrement counter
- Automatically changing random word/quote display
- Supporting pages for country and cricket examples

## 🛠️ Technologies Used

- **HTML5** — Structure and content
- **CSS3** — Layout, colors, spacing, grid, buttons, and visual styling
- **Vanilla JavaScript** — DOM manipulation, events, counter logic, color changes, and random content
- **GitHub Pages** — Static website deployment

## 🚀 Run the Project Locally

No build tools or external packages are required.

### Option 1: Open directly

1. Clone the repository:

   ```bash
   git clone https://github.com/Sanjeet3065/Web-Design-And-Development-Deployment.git
   cd Web-Design-And-Development-Deployment
   ```

2. Open `index.html` in any modern web browser.

### Option 2: Use a local server

If you use VS Code, open the project with the **Live Server** extension. You can also run a simple local server with Python:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## 📌 Important Notes

- The forms are demonstration forms and do not send data to a backend.
- The project does not use a database or server-side application.
- Some pages and interactions are intentionally simple so that the underlying concepts remain easy to understand.
- Image filenames contain spaces; keep the filenames unchanged unless the references in `index.html` are updated as well.
